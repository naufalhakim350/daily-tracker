Kenapa Keluar "404 File Not Found"?

Jika anda nampak paparan 404, semak 5 punca utama ini:

  • Masa Deployment: GitHub mengambil masa 1 hingga 5 minit untuk membina laman web selepas dimuat naik. Tunggu sebentar dan refresh.
  • Nama Fail Mestilah `index.html`: Mesti huruf kecil sepenuhnya. Jangan guna Index.html, main.html, atau index.html.txt.
  • Lokasi Fail: Pastikan fail index.html berada di lapis paling luar (root), bukan di dalam sebarang sub-folder.
  • Tetapan Branch: Di GitHub Repository → Settings → Pages, pastikan Branch dipilih ke main (atau master) dan folder ke / (root).
  • Format URL Betul: Format URL yang betul ialah:
    https://USERNAME.github.io/REPOSITORY-NAME/

Panduan Langkah Muat Naik:

  1. Simpan Fail Ini:

    Muat turun fail ini dan pastikan nama fail ialah tepat index.html.

  2. Cipta Repository Baru di GitHub:

    Log masuk ke GitHub.com, tekan butang "New Repository". Namakan repository seperti daily-tracker dan pilih Public.

  3. Upload Fail index.html:

    Di dalam repository baharu, klik link "uploading an existing file", kemudian tarik (drag & drop) fail index.html. Tekan "Commit changes".

  4. Aktifkan GitHub Pages:

    Pergi ke tab Settings → Pages di sidebar kiri → Tukar Branch None kepada main → Tekan Save.
